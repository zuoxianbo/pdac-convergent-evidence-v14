# Pancreatic cancer convergent-evidence scoring — NCS benchmark V14.1

Code + data package for the **convergent multi-evidence target-prioritisation**
benchmark used in the *Nature Computational Science* (NCS) submission on pancreatic
ductal adenocarcinoma (PDAC). This is the **V14.1 submission-readiness revision** of the
honest V14 benchmark: every statistic is recomputed on a single paired gene set, the
narrative is contracted to one central thesis, and the previously-claimed "ECS superiority"
is replaced by an honest component-attribution result. V14.1 additionally applies a full
NCS *Analysis* editorial pre-screen (34-point review): tightened claims, an NCS-style
concept-first abstract, expanded reproducible Methods, and a Data & code availability
statement.

> **Central thesis (single, contracted argument).**
> *"Evidence is not information; the right — conjunctive — evidence is."*
> Multimodal fusion helps **only** when the target property is itself conjunctive and cannot
> be encoded by a single strong predictor axis (here, protein-network topology). Where the
> endpoint is topology-encoded, STRING centrality alone is optimal and fusion is redundant —
> including the prospectively defined **E6 negative-control endpoint**.

## Headline results (honest, paired gene sets, no leakage)

- **E3 actionable target (the only convergent endpoint):** ECS AUROC **0.812** vs
  STRING **0.725** → DeLong Δ-AUROC **0.087** [95% CI 0.077–0.097], **p < 0.001**.
- **Component attribution (the key honest finding):** the *entire* E3 gain is
  **druggability-driven**. STRING 0.725 → +druggability **0.879** (+0.154, the single
  largest step) → +genetics ≈ 0 → +tissue ≈ 0. Full ECS **0.812** sits *below* the targeted
  STRING+druggability baseline (0.879) because PHI dilutes druggability with four
  uninformative layers. Leave-one-out: removing druggability drops E3 to 0.679.
- **E6 negative control** ("*Established clinical targets are already encoded by network
  topology*")**:** STRING **0.985** > ECS **0.929** (n ClinicalTrials.gov PDAC targets, never
  used inside ECS).
- **ECS-specific targets (recovery, not superior enrichment):** E3-positive genes rise from
  mean rank **5652** (STRING) to **4051** (ECS); top-100 ECS ∩ top-100 STRING overlap = only
  a few genes. Fisher test ECS-specific vs STRING-specific: OR **0.62**, p **0.37** (not
  significant). Value = *re-ranking / recovery*, not raw enrichment.
- **Complementarity is concentrated in one layer:** druggability is the only support layer
  with meaningful incremental E3 gain; the other four contribute ≈ 0. Orthogonality =
  incremental predictive content, not statistical independence.

## Data provenance (external raw sources — **not** committed)

The committed `data/*.json` files are processed artifacts. Their raw upstream sources are:

| Layer / endpoint        | Raw source (obtain separately)                              |
|-------------------------|-------------------------------------------------------------|
| `string_centrality`     | STRING v11 network (Szklarczyk et al. 2019)                |
| `mutation_freq`         | Pan-Cancer mutation frequency / OncodriveCLUST              |
| `impc_animal_ko`        | IMPC genotype–phenotype (Dickinson et al. 2016)            |
| `druggability`          | DGIdb 4.0 (Freshour et al. 2021)                           |
| `cancer_driver` / GWAS  | Open Targets Platform (Ochoa et al. 2021)                  |
| `hpa_*`                 | Human Protein Atlas (Uhlén et al. 2015/2017)               |
| `E1/E5` dependency      | DepMap CRISPR gene effect (CRISPRGeneEffect 26Q1)          |
| `E6` clinical validation| ClinicalTrials.gov PDAC target listings                   |

The `data_generation/` scripts document exactly how each committed JSON was produced. They
expect the raw files on disk (paths configurable via `V14_ROOT` / `V14_SKILL_DB`); the
committed `data/` artifacts let the `analysis/` pipeline run **without** re-downloading anything.

## V14.1 revision — what changed (NCS *Analysis* pre-screen, 34-point review)

`build_manuscript_v14_1.py` → `results/Pancreatic_cancer_convergent_evidence_NCS_V14.1.docx`.
All statistics are unchanged from V14 (same `benchmark_v14.json`); the changes are
manuscript-level, tightening the submission for NCS:

- **Abstract** rewritten concept-first and compressed to **142 words** (NCS target 100–150);
  drops the mean-rank detail, keeps the E3 Δ-AUROC 0.087 and the druggability attribution.
- **P0-2** "formal principle" → "*testable computational principle*."
- **P0-3** "intrinsically conjunctive" → "*explicitly conjunctive by construction*" (E3).
- **P9** "generalisable boundary" → "*testable task-dependent principle*"; "any
  prioritisation problem" → "*other target-prioritisation settings*."
- **E5 reclassified** from "topology-encoded" to **cross-domain transfer** (generalisation
  under tissue shift); explicit 3-class endpoint taxonomy (topology-dominated E1/E4/E6 ·
  conjunctive E2/E3 · transfer E5).
- **E6** labelled **prospectively defined negative-control endpoint**; added exact stats
  (35 positives in a 19,622-gene universe; STRING AUROC 0.985, 95% CI 0.980–0.991; AUPRC
  0.135, CI 0.068–0.256; stable under 1,000× bootstrap / 1,000× permutation).
- **P29** leave-druggability-out ECS: removing druggability collapses E3 0.812 → 0.679,
  confirming the gain is the specific conjunct, not generic multimodal complexity.
- **P11/12 Methods** expanded: data provenance, z-scoring + missing-value imputation,
  E3 = 1,159 positives, E6 mapping, and an α/weight **sensitivity analysis** (E3 AUROC
  0.691→0.834 across α, always > STRING 0.725).
- **P13/15** new **Data and code availability** section (runnable repo, one-command
  reproduction; Zenodo DOI to be assigned at acceptance).
- **P10** first-use glosses for STRING, PHI, DepMap, NDCG, ECE (broad-readership).
- **Main text ≈ 1,910 words** (Intro 273 + Results 1,021 + Discussion 615) — within the
  NCS ≤ 3,500 limit; 6 display items retained.
